how to read it

Rack renders saved Git filters side by side as full-history 3D wavetable oscillators. In sync mode (default), scrubbing WT POS on any card or the master bar time-travels every oscillator and the overview strip to the exact same timestamp, showing live commit/churn counts and signed Δ diffs against the selected baseline oscillator.

Stage couples the full-history 3D wavetable (drag to orbit) to the repository read head and pairs it with an interactive 2D Commit Scope aligned 1:1 with the 32-slot overview strip. Hover any peak for a commit breakdown, click/scrub to inspect in 01 // COMMIT, or press Space to scan history with the LFO transport.

about gitwave

Read-only by design. Every gesture navigates, selects or filters. Action buttons only copy a git command; nothing is executed and no network call is made.

Real commit churn, merge cadence and agent activity from the frozen `.gitwave` history drive every 3D wavetable slice, 2D register wave and tension vector.

the data

The bundled history is a deterministic fictional repository, Orbit Notes: six refs, three releases, five pull requests and 46 agent-authored commits. The snapshot time is fixed at 2026-11-01 18:00 UTC. Open a .gitwave snapshot to replace it.
